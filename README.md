## Impetus

This topic is the first jump into geospatial analysis in `R`. There is a very high-level discussion of projections, ellipsoids, and datum, and then a dive into the data using the enigmatic Sonoran Desert bark beetle as a model data set.

## Module Learning Objectives

### Understand Spatial Reference Systems

> Learners will describe the importance of ellipsoids and datums in spatial data, and transform point data from one projection to another.

- **Bloom's Levels:** Understand, Apply
- **Reinforces:** Establishes the geospatial foundation (projections, datums) that every later spatial module (Raster Data, Shapefiles) builds on without re-explaining.
- **Notes:** This is the course's first geospatial topic, so the high-level conceptual grounding is treated as a prerequisite before any mapping is attempted.

### Visualize Spatial Point Data

> Learners will use `sf` and `ggplot` to visualize point data and create both static and dynamic maps.

- **Bloom's Levels:** Apply, Create
- **Reinforces:** Applies the `ggplot2` graphics skills from Graphics That Do Not Suck to a spatial context, using the Sonoran Desert bark beetle data set as a running example.
- **Notes:** Covering both static and dynamic maps previews the range of output formats available for spatial work later in the course.
